## 关于我们

圣七教育致力于为中小学提供前沿的 **STEM教育解决方案** ，帮助学生在创新实践中构建未来核心竞争力。我们专注于将国际优质教育资源本地化，打造系统化的课程与竞赛支持服务，推动跨学科融合式学习在中国校园落地生根。

我们提供涵盖基础建模、机械结构、城市规划、人工智能、可持续设计等方向的系统课程，支持学校建设创新实验室、科技社团、项目式学习课程和特色选修课，帮助学生夯实科学与工程基础，激发实践创造力。

圣七教育是多个国际知名赛事的合作方与认证机构，为学生提供从入门到精英级别的竞赛支持，服务对象覆盖小学高年级至高中阶段，帮助学生在“**WRO创意赛**”、“**F1在学校**”、“**未来工程师**”、“**未来之城**”等，自主研发创新课程引导学生将理论知识与实践知识相融汇，发挥想象力解决实际问题。

**助力莘莘学子努力做中国科创事业的推广者，参与者和传承者，成为既有家国情怀又有国际视野的有志青年！**
